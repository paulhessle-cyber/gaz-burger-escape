# 🍔 Gaz's Burger Escape

A tiny mobile-first arcade game made with plain HTML, CSS and JavaScript.

## Play locally
Open `index.html` in a browser.

## GitHub Pages
1. Upload the contents of this folder to the `gaz-burger-escape` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save. GitHub will give you the Pages URL.

## Controls
- Mobile: drag the joystick and tap **DASH**
- Desktop: WASD / arrow keys and Space / Shift

## Game
Survive the chefs, avoid the police, collect burgers, then reach the exit once it opens.
